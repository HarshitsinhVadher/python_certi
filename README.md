# freeCodeCamp - Data Analysis with Python Projects

This repository contains the complete solutions for all 5 certification projects required for the **Data Analysis with Python Certification** on [freeCodeCamp](https://www.freecodecamp.org/learn/data-analysis-with-python/).

All 5 projects are fully implemented, verified, and passing 100% of the unit tests (32/32 tests pass).

---

## 📁 Projects Overview

| # | Project | Folder | Description | Tests |
|---|---------|--------|-------------|:-----:|
| 1 | **Mean-Variance-Standard Deviation Calculator** | [`mean-variance-std-calculator/`](./mean-variance-std-calculator/) | Calculates mean, variance, std deviation, max, min, and sum along rows, columns, and matrix from a 3x3 array using NumPy. | 2/2 ✅ |
| 2 | **Demographic Data Analyzer** | [`demographic-data-analyzer/`](./demographic-data-analyzer/) | Analyzes demographic data extracted from the 1994 Census database using Pandas to answer demographic questions. | 10/10 ✅ |
| 3 | **Medical Data Visualizer** | [`medical-data-visualizer/`](./medical-data-visualizer/) | Cleans and visualizes medical examination data with categorical plots and heatmaps using Seaborn and Matplotlib. | 4/4 ✅ |
| 4 | **Page View Time Series Visualizer** | [`page-view-time-series-visualizer/`](./page-view-time-series-visualizer/) | Analyzes daily page views on the freeCodeCamp forum using line charts, bar charts, and box plots to identify patterns and growth. | 10/10 ✅ |
| 5 | **Sea Level Predictor** | [`sea-level-predictor/`](./sea-level-predictor/) | Predicts global average sea level change through year 2050 using historical data and linear regression with SciPy and Matplotlib. | 6/6 ✅ |

## 🛠️ Requirements & Installation

- Python 3.9+
- Libraries: `numpy`, `pandas`, `matplotlib`, `seaborn`, `scipy`

Install dependencies:
```bash
pip install numpy pandas matplotlib seaborn scipy
```
